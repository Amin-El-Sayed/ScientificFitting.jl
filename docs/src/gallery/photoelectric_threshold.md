# Photoelectric Work Function

This workflow estimates the work function of a metal from photoelectric
stopping-voltage measurements. The important step is not "fit a line"; it is to
use the line only in the physical region where electrons are emitted, propagate
the fitted covariance into derived quantities, and make the extrapolation
visible in the plot.

## Question

Light with frequency ``\nu`` ejects electrons only if the photon energy exceeds
the material work function ``\Phi``. The measured stopping voltage ``U_0`` tells
us the maximum kinetic energy of the electrons:

```math
e U_0 = h\nu - \Phi.
```

The analysis answers three questions:

- What is the fitted Planck constant ``h`` from the slope?
- What is the work function ``\Phi`` from the y-intercept?
- Where is the threshold frequency ``\nu_0`` where emission starts?

## Data

The measured columns are wavelength, stopping voltage, and their standard
uncertainties. Wavelength uncertainty is converted to frequency uncertainty
before fitting:

```math
\nu = \frac{c}{\lambda},
\qquad
\sigma_\nu =
\left|\frac{\partial \nu}{\partial \lambda}\right|\sigma_\lambda
= \frac{c}{\lambda^2}\sigma_\lambda.
```

The last two points are at zero stopping voltage. They are below the emission
threshold and are shown in the plot, but they are not used in the linear fit.
Including them in an unconstrained straight-line fit would estimate the wrong
thing: a smooth line through a kinked physical threshold.

## Model

For emitted electrons the model is linear:

```math
U_0(\nu_\mathrm{THz}) = m\nu_\mathrm{THz} + b.
```

With frequency measured in THz,

```math
m = \frac{10^{12}h}{e},
\qquad
b = -\frac{\Phi}{e}.
```

Because one electronvolt is the energy gained by one electron across one volt,
the work function in electronvolts is numerically simple:

```math
\Phi[\mathrm{eV}] = -b[\mathrm{V}].
```

The threshold frequency is the x-intercept:

```math
\nu_0 = -\frac{b}{m}.
```

## Fit

This is the complete analysis code for the numbers shown in the documentation
figure. The figure itself is generated by
`examples/gallery/09_docs_gallery_suite.jl`, which adds the intercept marker,
threshold marker, 1-sigma fit-uncertainty band, and side report panel.

```julia
using JuFitter
using LinearAlgebra

const c = 299_792_458.0
const elementary_charge = 1.602176634e-19

wavelength_nm = [150.0, 200.0, 250.0, 300.0, 350.0,
                 400.0, 450.0, 500.0, 550.0, 600.0]
voltage_V = [5.99, 3.87, 2.69, 1.78, 1.28,
             0.77, 0.50, 0.15, 0.0, 0.0]
sigma_wavelength_nm = fill(0.01, length(wavelength_nm))
sigma_voltage_V = fill(0.04, length(voltage_V))

frequency_THz = @. c / (wavelength_nm * 1e-9) / 1e12
sigma_frequency_THz = @. c * (sigma_wavelength_nm * 1e-9) /
                         (wavelength_nm * 1e-9)^2 / 1e12

fit_mask = voltage_V .> 0.0
linear_photo_model(nu_THz, p) = @. p[1] * nu_THz + p[2]

result = fit_model(
    linear_photo_model,
    frequency_THz[fit_mask],
    voltage_V[fit_mask];
    p0=[0.004, -2.2],
    sigma_y=sigma_voltage_V[fit_mask],
    sigma_x=sigma_frequency_THz[fit_mask],
    bounds=([0.0, -20.0], [0.02, 5.0]),
    initial_guesses=[[0.004, -2.2], [0.0042, -2.6], [0.0038, -1.8]],
)

slope, intercept = result.params
covariance = result.param_covariance

h_fit = slope * elementary_charge / 1e12
sigma_h = sqrt(covariance[1, 1]) * elementary_charge / 1e12

work_function_eV = -intercept
sigma_work_function_eV = sqrt(covariance[2, 2])

threshold_THz = -intercept / slope
threshold_gradient = [intercept / slope^2, -1 / slope]
sigma_threshold_THz = sqrt(dot(threshold_gradient,
                               covariance * threshold_gradient))

println("h = ", h_fit, " +/- ", sigma_h, " J s")
println("Phi = ", work_function_eV, " +/- ", sigma_work_function_eV, " eV")
println("nu0 = ", threshold_THz, " +/- ", sigma_threshold_THz, " THz")
println(diagnostic_dashboard_text(result))
```

## Error Propagation

The fit returns the local covariance matrix of the slope and intercept:

```math
V =
\begin{pmatrix}
\sigma_m^2 & \mathrm{cov}(m,b) \\
\mathrm{cov}(m,b) & \sigma_b^2
\end{pmatrix}.
```

The work-function uncertainty is direct because ``\Phi[\mathrm{eV}] = -b``:

```math
\sigma_\Phi = \sigma_b.
```

For the threshold frequency, use first-order covariance propagation:

```math
\sigma_{\nu_0}^2 =
\begin{pmatrix} b/m^2 & -1/m \end{pmatrix}
V
\begin{pmatrix} b/m^2 \\ -1/m \end{pmatrix}.
```

This matters because slope and intercept are usually correlated. Treating
``m`` and ``b`` as independent can understate or overstate the threshold
uncertainty.

## Reading The Plot

The blue line is the fitted linear emission-region model extrapolated to show
both the y-intercept and the threshold crossing. The band is a 1-sigma
fit-uncertainty band from the parameter covariance, not a prediction band for
future measurements. Error bars show the measured voltage uncertainty and the
propagated frequency uncertainty.

The zero-voltage points are plotted separately because they locate the physical
cutoff but are not part of the linear above-threshold regime. A good plot should
make that modeling choice visible; otherwise a reader cannot tell whether the
threshold was fitted, excluded, or silently ignored.

## Diagnostics

For this workflow, the first checks are practical:

- ``\chi^2/\mathrm{ndf}`` should be of order one if the linear model and
  uncertainties are realistic.
- The residuals above threshold should not bend systematically; curvature would
  signal contact potentials, wavelength calibration errors, or a bad threshold
  selection.
- The fitted threshold should lie between the last emitted and first
  non-emitted measurements, not far outside the observed transition.
- A profile scan of the slope or intercept is useful when the threshold region
  is sparse, because local covariance can look too confident near a kink or
  bound.

The documentation figure uses a local 1-sigma band. If a diagnostic dashboard
reports a review or stop condition, the next step is not styling the plot; it is
checking the model range, uncertainty model, and profile intervals.

## What Can Go Wrong

Do not fit all points with one straight line. Below threshold the physical model
is not linear; it is clipped at zero because no electrons are emitted.

Do not report the y-intercept without its uncertainty. The work function is a
derived quantity and inherits the intercept uncertainty directly.

Do not hide the extrapolation. The intercept and threshold are not measured
points; they are consequences of the model. They should be marked in the plot
so the reader sees how far the conclusion depends on the fitted line.

Do not overinterpret a good-looking line. If the residuals curve, the p-value is
implausibly small, or the profile is non-parabolic, the local symmetric errors
are not enough evidence for a careful scientific report.
