# Damped Oscillator Data

`pohl_wheel_free_decay.csv` is a curated laboratory dataset for a freely
decaying mechanical oscillator.

Columns:

- `time_s`: time in seconds.
- `phi_rad`: angular displacement in radians.
- `sigma_phi_rad`: standard uncertainty of the angular displacement.

The file contains a compact, fit-ready subset of a longer measurement. It is
intended for documentation, plotting, and regression examples; raw acquisition
notes and unrelated laboratory files are intentionally not distributed.
